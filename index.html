EDC15M

Open-source map editor and firmware analysis for Bosch EDC15. Everything runs in your browser: files are never uploaded.

Открытый редактор карт и разбор прошивок Bosch EDC15. Всё работает в вашем браузере: файлы никуда не отправляются.

Map editorРедактор карт Open a dump, compare with stock, edit maps, recalculate the checksum. Открыть дамп, сравнить со стоком, поправить карты, пересчитать контрольную сумму. Frontera analysisРазбор Frontera Opel Frontera B X22DTH, 0281001791: memory, tasks, fuel, boost and EGR chains, 92 maps tied to the code. Opel Frontera B X22DTH, 0281001791: память, задачи, цепочки подачи, наддува и EGR, 92 карты с привязкой к коду. Terrano analysisРазбор Terrano Nissan Terrano II 2.7 TDi, 0281001550: memory, process table, fuel chain, 58 maps tied to the code. Nissan Terrano II 2.7 TDi, 0281001550: память, таблица процессов, цепочка подачи, 58 карт с привязкой к коду. Source codeИсходники Code, documentation, map definitions and analysis tools. Issues and pull requests welcome. Код, документация, описания карт и инструменты разбора. Issues и pull request приветствуются.

The two ECUs share the same hardware generation: C167 with mask ROM, the same memory layout and ROM routines. Map addresses differ between them.

Оба блока одного поколения железа: C167 с масочным ПЗУ, одинаковая карта памяти и подпрограммы ПЗУ. Адреса карт у них разные.

For research and off-road vehicles only. Changing the calibration can damage the engine, the injection pump or the ECU. No warranty, use at your own risk. Firmware dumps are not published here.

Только для изучения и техники вне дорог общего пользования. Правка калибровки может повредить двигатель, ТНВД или блок. Без гарантий, на свой риск. Дампы прошивок здесь не публикуются.
