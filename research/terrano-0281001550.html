Code-level analysis of the stock dump of the earlier 2.7 TDi (TD27ETi) ECU. 40,657 instructions decoded with the C166 disassembler, about 450 functions, a process table of 60 entries and 58 calibration maps (77 references) tied to the functions that read them and to the variables on their axes.

Same generation as the Frontera

0281001791 ≈ 0281001550

Same hardware and memory layout as the Frontera X22DTH ECU. Two flash chips, C167 with mask ROM, code at 0x10000–0x37FFF, calibration at 0x38000–0x3FFFF through DPP0/DPP1 = 0x0E/0x0F, the same task prologue and the same ROM routine addresses (map interpolation 00:20D6 / 00:20AC, task exit 00:07B4). Frontera tools and findings carry over; map addresses do not.

ROM 26FC

The pump metering controller is in ROM. The flash computes the metering setpoint FC56 and passes it straight to CALLS 00:26FC. There is no PI controller and no PWM/CAPCOM2 write in the flash, so the controller gains cannot be changed. The whole fuel chain up to the setpoint is in the flash.

68 mg

Hard fuel limit in the parameter block. It limits fuel independently of every map ECM Titanium lists; above 68 mg it has to be raised too.

Two datasets

The code works with the dataset at 0x38000 (DPP0 = 0x0E, DPP1 = 0x0F at startup). The copy at 0x00000–0x07FFF has the same layout and differs in 812 bytes, mostly the “fuel → metering” map and two rpm × fuel maps. No code switches to it and the CPU sees ROM at these addresses, so it is most likely unused. Addresses of the same map in the two sets differ by 0x38000; ECM Titanium shows the 0x0xxxx addresses and writes to both sets.

Tuning notes

  • Raise driver demand, the smoke limiter and the rpm limiter. Edit the “fuel → metering” map 0x3E3E0 only to extend it when the new fuel exceeds the top of its axis (65 mg): editing it directly bypasses every limiter and smoke control.
  • After editing the metering map in Titanium, check that 0x3E3E0 changed by the same percentage and was not overwritten with the values of the second set, because the two copies differ.
  • ECM’s second “phase of injection” at 0x04842 (0x3C842 in the working set) has no axis header and is read by no code or pointer table; possibly read by ROM.
  • The TD27 is known for cylinder head cracking from overheating: use an exhaust gas temperature gauge for any fuel increase.

What the dump does not contain

  • The scheduler, interrupts and the pump metering controller: they are in the mask ROM.
  • The internals of ROM routines (interpolation, filters, fault reporting): visible only through their arguments and results.
  • The immobilizer (NATS) check, which is also in ROM.
